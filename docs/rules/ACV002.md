# ACV002: Reserved (deployment validation)

**ACV002 is reserved for deployment validation and is not raised by this release.**

| | |
| --- | --- |
| Code | `ACV002` |
| Kind | Validation code: the input is rejected |
| Exit code | none (reserved) |
| Specification | [AI Change Provenance §6.6](../../spec/ai-change-provenance.md#66-validation) |
| Raised by | nothing (reserved; see [model](../model.md)) |

## Why it matters

Deployment facts are not part of this version of the model (ACC004 and ACC005, the deployment and
bypass rules, are reserved too). The code is held so that it is never reused for something else:
retired and reserved identifiers are never recycled.

## Status

Reserved. No release of `acc` raises it, there is no example, and nothing needs fixing. If a
future specification version defines deployment validation, this page will describe it.
